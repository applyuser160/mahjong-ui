# mahjong-ui 画面機能仕様書

本ドキュメントでは、`mahjong-ui` が提供する各画面・UIコンポーネントの機能要件および画面構成を解説します。

---

## 1. 4人対局画面 (TableLayout)

CPU 3名を相手にしたリアルタイム対局画面です。

```
+-------------------------------------------------------------+
| [東4局 1本場 供託:1] 残り牌: 68枚      ドラ表示牌: [一萬]   |
+-------------------------------------------------------------+
|                         対面 (CPU 2)                        |
|                     [河] [手牌: 13枚]                       |
|                                                             |
| 上家 (CPU 3)                                    下家 (CPU 1)|
| [河] [手牌]                                     [河] [手牌] |
|                                                             |
|                         自家 (Player)                       |
| [AI HUD: 推奨打牌 / EV / 和了率]                            |
| [ツモ切り / 手出し表示]                                     |
| [手牌: 14枚 (ソート済み)]                                   |
| [アクションプロンプト: ツモ / ロン / ポン / チー / リーチ]  |
+-------------------------------------------------------------+
```

### 機能要件
- **卓上表示**:
  - 各家の持ち点、風（東/南/西/北）、リーチ棒、本場表示
  - 牌山残り枚数、ドラ表示牌（王牌）
  - 各家の河（ツモ切り牌は半透明または判別表示、リーチ宣言牌の横向き表示）
- **プレイヤー操作**:
  - 打牌選択（クリックで打牌）
  - ツモ和了・ロン和了
  - リーチ宣言（リーチボタン押下後に打牌選択）
  - 鳴き（ポン・チー・カン・パス）
- **二重送信防止**:
  - ボタン連打による通信重複防止（Submittingステートによるガード）

## 2. リアルタイム AI HUD (AiHud)

プレイヤーの手番時に、Rust コアエンジンによる局収支 EV 探索結果をリアルタイム表示します。

### 表示項目
- **推奨打牌ランキング**:
  - 第1候補〜第3候補の推奨打牌
  - 各打牌の局収支 EV（点数期待値）
  - 想定和了率 (%)
  - 想定打点 (点)
  - 放銃リスク (%)
- **着順期待値 (Placement EV)**:
  - 点棒状況・ウマ・オカを考慮した最終着順確率分布（1位〜4位の確率）
- **向聴数 & 有効牌**:
  - 現在の向聴数
  - 有効牌（受入れ牌）の一覧と残り枚数合計

## 3. 何切るドリル画面 (DrillView)

Rust コアエンジンが自動生成した「何切る」問題に挑戦できる特訓画面です。

### 機能要件
- **問題表示**:
  - 難易度選択（初級・中級・上級）
  - 出題手牌（14枚）およびドラ表示牌
  - 巡目・点況設定
- **解答とフィードバック**:
  - 切る牌をクリックして解答
  - AI による正誤判定（最適手との EV 比較）
  - 思考プロセスの解説文（Explanation）の自動表示
  - 全打牌候補の EV ランキングテーブル

## 4. 終局後検討・牌譜レビュー画面 (ReviewView)

対局終了後に、全巡目の打牌を AI が自動分析・評価する検討画面です。

### 機能要件
- **悪手ハイライト**:
  - プレイヤーの打牌のうち、最適手から一定以上の EV 損失があった巡目を自動検出
  - 疑問手 (Inaccuracy: $\Delta EV \ge 150$)
  - 悪手 (Mistake: $\Delta EV \ge 500$)
  - 大悪手 (Blunder: $\Delta EV \ge 1500$)
- **代替手の提示**:
  - AI が推奨した手と、その理由（受入れ広さ、打点、守備力）を比較表示
- **レーティング評価**:
  - 1局全体の総合プレイングスコアおよび悪手率の算出
